# House Price Prediction using Linear Regression
## SkillCraft Technology - Machine Learning Internship
### Task 1
## Objective
The objective of this project is to build a Linear Regression model that predicts house prices based on house area, number of bedrooms, and number of bathrooms.

## Dataset
- Housing.csv
## Technologies Used

- Python
- Pandas
- Matplotlib
- Scikit-learn
## Machine Learning Algorithm
- Linear Regression
## Features Used
- Area
- Bedrooms
- Bathrooms
## Steps Performed
- Loaded the dataset
- Selected input features and target variable
- Split the dataset into training and testing sets
- Trained a Linear Regression model
- Predicted house prices
- Evaluated the model using MAE, MSE, and R² Score
- Visualized Actual vs Predicted house prices
## Model Evaluation
- Mean Absolute Error (MAE)
- Mean Squared Error (MSE)
- R² Score

## Conclusion
This project demonstrates how Linear Regression can be used to predict house prices using important housing features. It provides a basic understanding of supervised machine learning, model training, prediction, and evaluation.
